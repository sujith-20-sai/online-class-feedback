# Online Class Feedback Form

A modern, responsive online class feedback form built with HTML5, CSS3, and JavaScript, featuring an educational banner image and interactive feedback options.

## Features
- **Online Class Banner Image** header
- **Student & Subject Information**
- **Structured Feedback Questions**:
  1. Overall online class experience
  2. Clarity of instructor explanation
  3. Class content usefulness
  4. Interaction during class
  5. Overall satisfaction level
  6. Suggestions / comments textarea
- **Interactive Feedback Submission Screen** without page reload
- **Responsive Layout** for mobile, tablet, and desktop

## Demo
Open `index.html` or `file.html` directly in any web browser.
